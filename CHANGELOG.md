# Changelog

## 1.0.0 — 2026-09-30

First public version.

- **Ledger:** resume (.docx / .pdf / .txt) → numbered evidence items; skills split into "shown in work" vs "only listed"; inline editing.
- **Job Fit:** requirement extraction (required / duty / preferred / eligibility), evidence matching, fit score and recommendation.
- **Scholars:** Semantic Scholar search by topic or name with arXiv fallback, researcher ranking, affiliation filter, 24 h cache.
- **Studio:** cover letters, tailored resume bullets and outreach emails; sentence-level verifier; live re-verify after edits.
- **Pipeline:** drag-and-drop application board with follow-up dates.
- Optional LLM writers (Claude, OpenAI, Ollama) with one verifier-driven repair round.
- Claim-injection benchmark and 26 tests; GitHub Actions on Python 3.10–3.12.
